---
description: Gera um desafio de código aleatório baseado em nível e tecnologia
argument-hint: <tecnologia> <nivel>
---

O usuário quer um desafio de código. Os argumentos fornecidos são: **$1** (tecnologia) e **$2** (nível).

Siga estas regras:

1. Se a tecnologia **não foi informada** ($1 está vazio), pergunte ao usuário qual tecnologia deseja (ex: JavaScript, Python, TypeScript, React, Node.js).
2. Se o nível **não foi informado** ($2 está vazio), pergunte ao usuário o nível desejado: `iniciante`, `intermediário` ou `avançado`.
3. Com tecnologia e nível definidos, **gere um desafio original e aleatório** — nunca repita o mesmo desafio duas vezes.

Formate o desafio assim:

---

# ⚔️ Desafio de [tecnologia] — Nível [nivel]

## 📋 Descrição
[Descrição clara do problema a ser resolvido]

## 🎯 Objetivo
[O que o código deve fazer / o resultado esperado]

## 📥 Entrada
[Descrição dos dados de entrada, se houver]

## 📤 Saída esperada
[Descrição ou exemplos do resultado esperado]

## 💡 Dica
[Uma dica sutil sem entregar a solução]

## 🏆 Critérios de conclusão
- [ ] [Critério 1]
- [ ] [Critério 2]
- [ ] [Critério 3]

---

> 💬 Quando terminar, compartilhe seu código aqui e eu farei um code review completo!

---

**Diretrizes por nível:**
- **iniciante**: problemas simples, conceitos básicos, sem abstrações complexas.
- **intermediário**: uso de estruturas de dados, lógica mais elaborada, boas práticas.
- **avançado**: algoritmos, performance, padrões de projeto, edge cases.
